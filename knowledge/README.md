# 知识库使用说明

这个目录存放你的**个人投资笔记**。投资顾问模块（AdvisorTab）在回答问题时会读取这里的所有
Markdown 文件，把你的经验和纪律作为最高优先级的判断依据。

## 怎么用

1. 在这个目录下（或子目录）新建 `.md` 文件，写下你的投资原则、复盘记录、教训
2. 保存即生效，无需重启服务（模块会按文件修改时间自动刷新缓存）
3. 在"投资顾问"页面提问时，相关笔记会自动注入到模型上下文

## 建议的文件组织

```
knowledge/
├── principles.md          # 投资原则与纪律（最重要）
├── option-playbook.md     # 期权策略手册
├── lessons.md             # 历史教训复盘
├── valuation.md           # 估值方法与标准
└── watchlist/             # 个股专项笔记
    ├── AAPL.md
    └── TSLA.md
```

## 写作建议

**写成可执行的规则，而不是感想。** 模型需要能据此给出具体参数。

不好的写法：
> 我觉得要在低位买入，不要追高。

好的写法：
> 入场纪律：只在价格低于 MA60 且 RSI < 40 时开始建仓，首仓不超过计划仓位的 1/3。
> 若继续下跌 8%，加第二仓；再跌 8%，加第三仓。三仓打完不再加。

**明确写出你的失败教训和触发条件。** 这是模型最难从通用知识中获得的部分。

> 教训（2024-03 NVDA）：在财报前 3 天卖了 Put，财报暴雷后被行权，成本比市价高 22%。
> 规则：财报前 7 天内不新开 Sell Put 仓位。

## 容量限制

- 知识库总量在 60,000 字符以内时全量注入
- 超过后按与问题的关键词相关度取 Top 8 篇
- 单篇超过 12,000 字符会被截断，建议拆分成多个主题文件

## 隐私

这些文件只在本地读取，随请求发送给你配置的 LLM 服务。如果笔记涉及敏感的持仓规模或资金量，
建议用相对比例（"计划仓位的 1/3"）而不是绝对金额。
